# Установка и первый запуск Unofficial TelegramNewsAI 5.5.0 Stable

**[Скачать PDF-памятку](https://github.com/ccuriu/Unofficial-TelegramNewsAI/releases/download/v5.5.0/Unofficial-TelegramNewsAI-5.5.0-Quick-Start.pdf)**

Эта инструкция рассчитана на обычного пользователя Windows 10/11. Для первого запуска достаточно доступа к своему Telegram-аккаунту и 5-10 нужных каналов.

> **Главное:** сначала распакуйте архив в постоянную папку. Установщик работает прямо в этой папке и создаёт ярлык на неё. После установки папку не удаляйте и без необходимости не переносите.

## 1. Скачайте и распакуйте программу

1. Откройте [последний Stable Release](https://github.com/ccuriu/Unofficial-TelegramNewsAI/releases/latest).
2. Скачайте `Unofficial-TelegramNewsAI-5.5.0-Stable-Windows.zip`.
3. Создайте постоянную папку, например `Документы\TelegramNewsAI`.
4. Щёлкните по ZIP правой кнопкой мыши → **Извлечь все...** и распакуйте содержимое в эту папку.
5. Откройте уже распакованную папку и запустите `INSTALL.bat`.
6. Дождитесь сообщения об успешной установке. Не закрывайте окно во время работы.

Если подходящего Python нет, установщик может установить Python 3.13 через Windows Package Manager. После установки на рабочем столе появится ярлык **Unofficial TelegramNewsAI**.

## 2. Получите API ID и API Hash

Для подключения используется ваш собственный Telegram API-доступ.

1. Откройте [my.telegram.org](https://my.telegram.org).
2. Войдите по номеру своего Telegram-аккаунта. Код подтверждения придёт в Telegram.
3. Откройте **API development tools**.
4. Если приложение для этого номера уже создавалось, используйте существующие данные. Новое создавать не обязательно.
5. Подготовьте два значения:
   - `api_id` — число;
   - `api_hash` — строка из 32 символов `0-9` и `a-f`.

> **Не передавайте другим людям:** API ID, API Hash, код входа, пароль 2FA, `credentials.bin` и файлы `telegram_session.session`.

## 3. Первый вход в Telegram

Запустите программу ярлыком **Unofficial TelegramNewsAI** на рабочем столе.

1. Когда появится `Введите API ID:`, введите только число с my.telegram.org и нажмите Enter.
2. Когда программа попросит API Hash, щёлкните **правой кнопкой мыши в окне**, затем нажмите **Enter**. Нужно вставить все 32 символа.
3. Введите номер, к которому привязан ваш Telegram-аккаунт, в международном формате: **+ код страны и номер**, затем нажмите **Enter**.
4. Введите код подтверждения из Telegram.
5. Если включена двухэтапная защита, введите пароль Telegram.

### Если API Hash не вставляется

Поле ввода скрыто, поэтому символы на экране могут не отображаться — это нормально. Для API Hash щёлкните **правой кнопкой мыши в окне**. Если вставка не сработала, запасной вариант — `Shift+Insert`.

Если программа сообщает о неправильной длине API Hash, повторите вставку этим способом и убедитесь, что введены все 32 символа без пробелов.

## 4. Выберите каналы

Для первого запуска лучше выбрать **5-10 реальных каналов**. Поддерживаемый максимум программы — **50 выбранных источников**.

Можно вводить:

- номера каналов из показанного списка;
- диапазоны, например `1,3,7-10`;
- `@username`;
- ссылки вида `https://t.me/channel`.

В одной строке можно смешивать номера и Telegram-адреса. Публичный канал можно добавить даже без подписки.

После основного выбора программа предложит необязательно добавить ещё публичные каналы. Если добавлять нечего — просто нажмите Enter.

## 5. Создайте первый дайджест

1. В главном меню нажмите Enter или введите `D`.
2. На вопрос `За сколько последних часов сделать выгрузку? [24]` для первого теста просто нажмите Enter — будет выбран период 24 часа.
3. Дождитесь завершения. Программа синхронизирует сообщения, соберёт выбранный период, обработает связанные публикации и сохранит файлы.

Первый запуск может занять больше времени, чем последующие. Не закрывайте окно, пока программа не закончит работу.

Если программа сообщает, что период загружен не полностью, сохраните результат и текст сообщения — это полезно для диагностики.

## 6. Где находится результат

После успешного завершения Проводник Windows автоматически откроется и выделит основной файл:

### `ДАЙДЖЕСТ_ДЛЯ_ИИ.md`

Компактный Markdown-дайджест для чтения и дальнейшего анализа. Его можно передать выбранному внешнему интеллектуальному агенту или ассистенту, чтобы получить общий обзор событий либо разбор конкретной темы.

Редакционная инструкция уже находится в начале файла. Обычно достаточно попросить сделать дайджест или указать интересующую тему.

### `ДАЙДЖЕСТ_ПОСЛЕДНИЙ.json`

Полный структурированный экспорт schema 8. Он нужен для проверки данных, совместимости и технического анализа. Для обычной работы чаще достаточно Markdown-файла.

> **TelegramNewsAI сам не отправляет Telegram-содержимое во внешние AI/ML-сервисы.** Пользователь сам выбирает, какой готовый файл и куда передать.

## 7. Обновление

Для будущих Stable-обновлений не нужно заново скачивать и распаковывать весь ZIP.

1. Скачайте один файл [`TelegramNewsAI_Update.cmd`](https://github.com/ccuriu/Unofficial-TelegramNewsAI/releases/latest/download/TelegramNewsAI_Update.cmd).
2. Запустите его двойным щелчком из любой папки.
3. Updater сам найдёт установленную программу. Если не сможет определить папку однозначно, предложит выбрать её.
4. Если программа сейчас работает, updater не завершает её принудительно: он ждёт обычного закрытия и затем продолжает обновление.
5. Telegram-сессия, credentials, настройки, выбранные каналы, база и дайджесты сохраняются.

## Если что-то не получилось

Для диагностики полезно сообщить:

1. что вы делали;
2. что ожидали;
3. что получилось;
4. полный текст ошибки или скриншот;
5. при необходимости — лог из папки `logs`.

Не отправляйте API Hash, код входа, пароль 2FA, `credentials.bin` и файлы `telegram_session.session`.

Первый тест считается успешным, если программа вошла в Telegram, сохранила выбранные каналы, создала дайджест за выбранный период и открыла папку с `ДАЙДЖЕСТ_ДЛЯ_ИИ.md`.
