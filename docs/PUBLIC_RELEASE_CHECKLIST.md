# Чек-лист повторного публичного релиза

Статус: **OPTIONAL / NOT PLANNED YET**. Этот чек-лист используется только если позже будет принято отдельное решение о публичном релизе. Он не ограничивает развитие приватной личной версии.

## 1. Telegram API / антиспам

- [ ] Этап 1: 5–7 дней обычных 24-часовых дайджестов на текущих 31 канале без наблюдаемого FloodWait, защитной остановки, повторной авторизации или ограничений аккаунта.
- [ ] Проверена защитная остановка 5.4.12 на синтетических/offline regression tests.
- [ ] После этапа 1 отдельно проверены 7 и 30 дней; 90 дней — только если предыдущие этапы спокойны.
- [ ] Рост числа каналов выполнялся ступенчато, без одновременного увеличения глубины истории.
- [ ] README описывает только фактически протестированные режимы и не обещает безопасный лимит.

## 2. Сессия и авторизация

- [x] Одновременный обычный запуск двух копий в одной Windows-сессии блокируется named mutex.
- [x] Существующая установка не начинает новую авторизацию автоматически, если пропал `telegram_session.session`.
- [x] Если сохранённая сессия перестала быть авторизованной, программа останавливается вместо запроса нового кода.
- [x] Любой FloodWait виден приложению и прекращает текущий сетевой этап.
- [x] Ошибки, похожие на ограничение/отзыв сессии, не ретраятся вслепую.
- [x] Обычный дайджест сначала использует локальный entity-cache и не вызывает полный `get_dialogs(limit=None)` без необходимости.

- [x] Программа сама не отправляет экспорт во внешний AI/ML-сервис.
