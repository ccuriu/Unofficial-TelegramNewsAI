# TelegramNewsAI 5.4.2 Stable

Переносимая сборка без личных данных, Telegram-сессии, выбранных каналов,
базы новостей и ранее созданных дайджестов.

## Установка на другом компьютере

1. Распакуйте архив в обычную папку, например `C:\TelegramNewsAI`.
2. Запустите `INSTALL.bat`. Он найдёт Python или предложит автоматическую установку,
   создаст отдельное окружение программы и установит Telethon.
3. Запустите `Telegram_Digest.exe` или созданный на рабочем столе ярлык.
4. При первом запуске введите Telegram API ID, API Hash и номер телефона,
   затем код подтверждения Telegram и выберите каналы.

Для получения API ID и API Hash используется страница `https://my.telegram.org`.
Эти сведения сохраняются только на текущем компьютере в зашифрованном файле
`credentials.bin`. Telegram-сессия, база и настройки также создаются локально.

## Основные команды

- `Enter` или `D` — дайджест за выбранный период.
- `S` — поиск по локальной базе с предложением обновить устаревшие каналы.
- `I` — состояние базы и каналов.
- `B` — первоначальная загрузка истории за 90 дней.
- `A`, `R`, `L`, `N` — управление каналами.
- `Q` — выход.

База хранит до 90 дней и ограничена 500 МБ. Поиск обычно экспортирует не более
1500 результатов и отдельно предлагает выгрузить всё. Смысловая модель отключена:
обычный быстрый поиск работает без неё и без скачивания сотен мегабайт.

## Перенос и обновление

Для чистой установки переносите только содержимое этого архива. Не копируйте
`credentials.bin`, файлы `*.session`, `news.db*`, `settings_free.json`,
`selected_channels.json`, папки `Дайджесты`, `logs` и `models`.

Чтобы закрепить программу на панели задач, запустите `Telegram_Digest.exe`,
нажмите правой кнопкой по значку на панели задач и выберите «Закрепить на панели задач».
