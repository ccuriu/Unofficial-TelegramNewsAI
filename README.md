# TelegramNewsAI 5.4.2 Stable

Локальный Windows-инструмент для сбора публикаций из выбранных Telegram-каналов, хранения истории в SQLite, быстрого тематического поиска и подготовки JSON для последующего анализа в ChatGPT.

Telegram Desktop для работы программы не нужен: подключение к Telegram выполняется напрямую через Telethon.

## Что умеет

- собирать новые публикации и недостающую историю выбранного периода;
- хранить локальную историю до 90 дней в `news.db`;
- отслеживать содержательные правки отдельно от просмотров, реакций и других метрик;
- сохранять предыдущие редакции сообщений;
- удалять только точные дубли, не теряя похожие публикации с отличающимися цифрами, именами или формулировками;
- выполнять быстрый локальный поиск через SQLite FTS5;
- при необходимости догружать устаревшие или неполные периоды из Telegram;
- формировать готовый `ДАЙДЖЕСТ_ПОСЛЕДНИЙ.json` и тематические поисковые выгрузки для ChatGPT.

## Скачать и установить

Для обычного пользователя удобнее использовать раздел **Releases** и скачать последнюю стабильную Windows-сборку.

Если Release ещё не обновлён до версии из `main`, можно скачать исходники репозитория и установить их тем же способом.

1. Распакуйте файлы в обычную папку, например `C:\TelegramNewsAI`.
2. Запустите `INSTALL.bat`.
3. Установщик найдёт Python или предложит установить Python 3.13 через Windows Package Manager, создаст отдельное `.venv` и установит зависимости из `requirements.txt`.
4. Запустите `Telegram_Digest.exe` или созданный ярлык.
5. При первом запуске введите собственные Telegram API ID, API Hash и номер телефона, затем код подтверждения Telegram и выберите каналы.

Telegram API ID и API Hash получают на `https://my.telegram.org`.

Если вы не хотите запускать готовый EXE, программу можно запустить через `start_free.bat` или напрямую командой:

```bat
.venv\Scripts\python.exe telegram_collector_free.py
```

## Основные команды

- `Enter` или `D` — обычный дайджест за выбранный период;
- `S` — тематический поиск по локальной базе с предложением обновить устаревшие каналы;
- `I` — состояние базы и каналов;
- `B` — первоначальное заполнение истории за 90 дней;
- `A` — добавить публичный канал;
- `R` — удалить канал;
- `L` — показать выбранные каналы;
- `N` — создать список каналов заново;
- `Q` — выход.

## Хранение и скорость

По умолчанию:

- история в SQLite — до 90 дней;
- максимальный размер базы — 500 МБ;
- тематический поиск экспортирует до 1500 наиболее релевантных результатов и при необходимости предлагает выгрузить всё;
- правки повторно проверяются только в небольшом недавнем окне, чтобы обычный дайджест не превращался в долгий полный перескан;
- тяжёлые функции вроде постоянного OCR, массовой проверки удалений и обязательной нейросетевой индексации отключены.

## Конфиденциальность

TelegramNewsAI не требует публикации личных данных. API ID, API Hash и номер телефона вводятся локально и сохраняются в `credentials.bin`, защищённом Windows DPAPI. Telegram-сессия, выбранные каналы, база новостей, логи и дайджесты также создаются только на компьютере пользователя.

`.gitignore` исключает чувствительные и рабочие файлы, включая:

- `credentials.bin` и резервные `credentials.unreadable-*.bin`;
- `*.session` и `*.session-journal`;
- `selected_channels.json`;
- `settings_free.json`;
- `news.db*`;
- `Дайджесты/`, `logs/`, `Резервные_копии/`, `models/`;
- `.venv/` и временные файлы.

Дополнительные правила: [SECURITY.md](SECURITY.md).
