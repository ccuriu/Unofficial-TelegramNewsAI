# TelegramNewsAI 5.4.1 Stable

Переносимая сборка для Windows без личных данных, Telegram-сессии, выбранных каналов, базы новостей и старых дайджестов.

## Быстрое восстановление

1. Откройте раздел **Releases** и скачайте `TelegramNewsAI-5.4.1-Stable-Windows.zip`.
2. Распакуйте архив, например в `C:\TelegramNewsAI`.
3. Запустите `INSTALL.bat`. Установщик найдёт Python либо установит его через Windows Package Manager, создаст отдельное окружение и установит Telethon.
4. Запустите `Telegram_Digest.exe`.
5. При первом запуске введите собственные Telegram API ID, API Hash и номер телефона, затем выберите каналы.

Данные Telegram API получают на https://my.telegram.org. Они сохраняются только на текущем компьютере в зашифрованном `credentials.bin`. Сессия, настройки и база тоже создаются локально.

## Основные команды

- `Enter` или `D` — дайджест за выбранный период.
- `S` — поиск по локальной базе.
- `I` — состояние базы и каналов.
- `B` — первоначальная загрузка истории за 90 дней.
- `A`, `R`, `L`, `N` — управление каналами.
- `Q` — выход.

База хранит до 90 дней и ограничена 500 МБ. Быстрый поиск работает без нейросетевой модели и без загрузки сотен мегабайт.

## Какие файлы никогда не публикуются

`.gitignore` исключает `credentials.bin`, `*.session`, `news.db*`, `settings_free.json`, `selected_channels.json`, папки `Дайджесты`, `logs`, `models`, виртуальное окружение и временные файлы.

Чтобы закрепить программу на панели задач, запустите `Telegram_Digest.exe`, нажмите правой кнопкой по значку и выберите «Закрепить на панели задач».
