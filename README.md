**Unofficial TelegramNewsAI** — неофициальная локальная Windows-утилита для личной работы с публикациями выбранных Telegram-каналов. Она синхронизирует выбранные источники, хранит локальную историю в SQLite, позволяет искать по архиву и формирует переносимые JSON/Markdown-экспорты для дальнейшего просмотра и анализа.

Проект не связан с Telegram FZ-LLC и не является официальным приложением Telegram. Telegram Desktop для работы не требуется.

**Программа сама не отправляет содержимое Telegram во внешние AI/ML-сервисы.** Встроенного AI API, облачного сервера и фоновой передачи экспортов нет. Пользователь сам решает, открывать экспорт вручную или передавать его выбранному внешнему инструменту. Историческое имя файла `ДАЙДЖЕСТ_ДЛЯ_ИИ.md` сохранено для совместимости и не означает автоматической передачи данных.

## Возможности

- последовательная синхронизация выбранных каналов через Telethon / MTProto;
- Unofficial TelegramNewsAI поддерживает максимум **50 выбранных каналов/источников** — это продуктовый предел проекта, а не официальный лимит Telegram;
- локальная база SQLite с историей, редакциями и поиском FTS5/LIKE;
- догрузка пропущенных публикаций в пределах выбранного периода;
- осторожная дедупликация без удаления содержательно отличающихся сообщений;
- Для публичных каналов источник по возможности ведёт непосредственно на конкретную исходную публикацию; ссылка на сам канал используется только как резервный вариант, если ссылка на пост недоступна. Если URL недоступен, программа не придумывает его и не добавляет отдельную ссылку «Открыть публикацию»;
- bounded continuity-context из локальных архивов без дополнительных Telegram-запросов;
- полный `ДАЙДЖЕСТ_ПОСЛЕДНИЙ.json`, компактный `ДАЙДЖЕСТ_ДЛЯ_ИИ.md` и `ПОИСК_ПОСЛЕДНИЙ.json`;
- Смысловой ML/embedding-поиск по Telegram-контенту не используется; локальный поиск работает через SQLite FTS5/LIKE;
- безопасное обновление программных файлов с сохранением пользовательского состояния.

## Как это работает

**Выбранные Telegram-каналы → локальная SQLite-база → выбранный период → JSON/Markdown-экспорт → просмотр или дальнейшая обработка по выбору пользователя.**

Сборщик не присваивает событиям «истинность» и не считает число перепечаток мерой достоверности. Экспорт сохраняет текст источника, время, ссылки, редакции и связи между сообщениями. Профиль 9.1 использует candidate-first Markdown; тематическое уточнение меняет отбор и подачу, но не отменяет прямые ссылки на исходные публикации.

## Установка

Для обычного пользователя рекомендуется готовый **[v5.5.0 Stable Release](https://github.com/ccuriu/Unofficial-TelegramNewsAI/releases/tag/v5.5.0)**.

1. Скачайте `Unofficial-TelegramNewsAI-5.5.0-Stable-Windows.zip`.
2. При желании сверьте SHA-256 с файлом `Unofficial-TelegramNewsAI-5.5.0-Stable-Windows.sha256.txt`.
3. Распакуйте ZIP в обычную пользовательскую папку.
4. Запустите `INSTALL.bat`.
5. При первом подключении введите собственные Telegram API ID и API Hash.
6. После установки запускайте программу ярлыком **Unofficial TelegramNewsAI** или `Telegram_Digest.exe`.

Поддерживаются Windows 10/11 и Python 3.10+. Установщик создаёт изолированное `.venv`.

Для разработки или проверки исходников можно скачать snapshot ветки `main`; готовый Release и исходный репозиторий соответствуют одной линии **5.5.0 Stable**. Исторические 5.4.x tags/Releases удалены, чтобы устаревшие сборки не выглядели как текущие.

### API ID и API Hash

Собственные API ID и API Hash выдаются на [my.telegram.org](https://my.telegram.org) → **API development tools**. Не публикуйте API Hash и не прикладывайте его к Issues. В репозитории нет общих пользовательских API-данных.

## Обновление

Для обновления достаточно одного переносимого файла `TelegramNewsAI_Update.cmd`. Его можно скачать в любую папку и запустить двойным щелчком.

Updater:
- автоматически ищет установленный Unofficial TelegramNewsAI по сохранённому пути и ярлыкам Windows;
- если установка не найдена однозначно, открывает обычное окно выбора папки;
- определяет последний опубликованный Stable Release на GitHub и фиксирует его конкретный commit;
- скачивает напрямую из публичного репозитория только программные файлы, перечисленные в `release_manifest.json`; release ZIP для обновления не скачивается и не распаковывается;
- перед заменой проверяет manifest и контрольную сумму launcher;
- не завершает работающую программу принудительно: текущий Telegram-сеанс не прерывается, updater ждёт обычного завершения программы и затем продолжает автоматически;
- при ошибке штатный `update.ps1` восстанавливает предыдущие программные файлы;
- сохраняет `telegram_session.session`, credentials, настройки, выбранные каналы, `news.db*`, дайджесты, логи, `.venv` и другие пользовательские файлы.

После успешного обновления выводится итоговая версия и сообщение, что программа находится в актуальном состоянии. Один и тот же `TelegramNewsAI_Update.cmd` можно использовать повторно для будущих Stable-релизов.

## Команды

- `Enter` или `D` — обычный дайджест;
- `S` — поиск по локальной базе;
- `B` — предварительное заполнение истории;
- `A` — добавить публичный канал;
- `R` — удалить канал;
- `L` — показать выбранные каналы;
- `N` — пересоздать список каналов;
- `I` — состояние базы и каналов;
- `T` — явно пересоздать Telegram-сессию;
- `0` — выход/отмена.

## Telegram API и защитный профиль

Telegram не публикует универсального безопасного числа каналов для сторонних клиентов; **точные критерии и лимиты не раскрываются**. Поэтому 50 источников — проверенный предел Unofficial TelegramNewsAI, а не обещание со стороны Telegram.

- `Telethon.flood_sleep_threshold = 0`, чтобы первый FloodWait был виден приложению;
- первый FloodWait, PEER_FLOOD, отзыв/потеря сессии и сходные защитные сигналы останавливают соответствующий сетевой этап;
- запросы истории идут последовательно, без агрессивного параллелизма;
- обычный запуск сначала использует локальный entity-cache;
- скрытая повторная авторизация запрещена; для восстановления есть явная команда `T`;
- две обычные копии блокируются системным mutex;
- каждый sync пишет локальный `API_SAFETY_SUMMARY` без секретов.

Реальная приёмка поддерживаемого режима 50 источников завершена без наблюдавшихся FloodWait, повторной авторизации или потери сессии. Это факт конкретных тестов, а не гарантия будущего поведения Telegram.

Техническая история испытаний: [docs/TELEGRAM_API_TESTING.md](docs/TELEGRAM_API_TESTING.md). Исследовательская фиксация условий платформы: [docs/TELEGRAM_API_TERMS_RESEARCH_2026-09-22.md](docs/TELEGRAM_API_TERMS_RESEARCH_2026-09-22.md).

## Правила платформы и сторонние сервисы

Unofficial TelegramNewsAI использует пользовательский Telegram API-доступ и не заявляет специального исключения из правил платформы. Пользователь отвечает за соблюдение применимых условий Telegram и прав на обрабатываемый контент.

Программа не содержит встроенной модели, не выполняет автоматическое обучение/дообучение моделей и не отправляет собранные публикации внешним AI/ML-провайдерам. Локальный поиск работает через SQLite FTS5/LIKE. Внешняя обработка экспортированного файла возможна только по отдельному действию пользователя.

Текущая пакетная архитектура не является полноценным интерфейсом чтения каналов и не запрашивает отдельный поток **Sponsored Messages**. Это задокументированное свойство текущей версии, а не заявление об универсальном исключении из Telegram API Terms. Если продуктовая модель изменится в сторону встроенного reader UI, hosted-сервиса или автоматической внешней обработки, применимость правил должна быть пересмотрена до такого релиза.

Официальные документы: [Telegram API Terms](https://core.telegram.org/api/terms), [Telegram Content Licensing](https://telegram.org/tos/content-licensing), [Sponsored Messages](https://core.telegram.org/api/sponsored-messages), [Creating your Telegram Application](https://core.telegram.org/api/obtaining_api_id).

## Конфиденциальность

API ID, API Hash и номер телефона вводятся локально. `credentials.bin` защищается Windows DPAPI. Telegram-сессия, настройки, список каналов, база, логи и экспорты остаются на компьютере пользователя.

Не публикуйте `credentials.bin`, `*.session`, API-данные, `news.db*`, `settings_free.json`, `selected_channels.json`, содержимое `Дайджесты`/`logs`/`Резервные_копии`, приватные URL и скриншоты с личными данными. Подробнее: [SECURITY.md](SECURITY.md).
