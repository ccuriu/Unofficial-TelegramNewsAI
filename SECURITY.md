# Безопасность и конфиденциальность

TelegramNewsAI работает локально и использует пользовательскую Telegram-сессию.

## Никогда не публикуйте

При создании Issue, Pull Request или при отправке диагностических файлов не прикладывайте:

- `credentials.bin`;
- любые `*.session` и `*.session-journal`;
- `news.db` и `news.db-*`;
- `selected_channels.json`;
- `settings_free.json`, если вы добавляли туда личные данные;
- содержимое папок `Дайджесты`, `logs`, `Резервные_копии`, если там есть личная информация.

Эти файлы исключены из Git через `.gitignore`, но пользователь всё равно должен проверять вложения перед публикацией.

## Telegram API

API ID, API Hash и номер телефона вводятся локально при первом запуске. Они сохраняются на компьютере пользователя в `credentials.bin`, защищённом Windows DPAPI. Telegram-сессия также хранится только локально.

## Сообщение об уязвимости

Если обнаружена уязвимость, связанная с утечкой Telegram-сессии, учётных данных или выполнением произвольного кода, не публикуйте секреты в открытом Issue. Опишите проблему без чувствительных данных и приложите минимальный воспроизводимый пример.

## Поддерживаемая версия

Исправления безопасности в первую очередь применяются к последней стабильной версии в ветке `main`.
